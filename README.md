# MetaQuest Action FPS

A Quake-inspired VR sci-fi shooter built with Unity and OpenXR for Meta Quest 3.

Currently in active development and testing. Features include laser combat, enemy state machines, hit effects, and VR player health feedback.

## Requirements

- Unity 6000.3.14f1
- Android Build Support for standalone Quest builds
- Meta Quest 3
- Meta Quest Link for testing in the Unity Editor on Windows

Unity package dependencies are recorded in Packages/manifest.json.

## Third-party assets

The MANNEQUIN character and animations from Adobe Mixamo are not included in this repository.

Download the character and the Idle, Walk, Stun, and Death animations separately from:
https://www.mixamo.com/

The local asset folder is Assets/Characters/Enemy/XXX. Reconnect model, Avatar, and animation references after importing. The project may show missing references until this setup is completed.

Third-party assets remain subject to their respective licences.

## Status

This is an experimental prototype. Gameplay, performance, and assets may change.
